# Judicial Explainer Bot

## About the Project

Judicial Explainer Bot is an educational chatbot designed to explain legal concepts, court procedures, legal terminology, and the Indian judicial system in simple English.

## Features

* Explains legal concepts in simple language.
* Answers questions about judicial procedures.
* Maintains conversation history.
* Provides a clear-chat option.
* Includes a legal information disclaimer.

## Technologies Used

* Python
* Streamlit
* LangChain
* Ollama
* Qwen 2.5 1.5B

## Run Locally

1. Install Python and Ollama.

2. Download the required model:

   `ollama pull qwen2.5:1.5b`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `streamlit run app.py`

## Disclaimer

This chatbot provides educational information only. It is not a substitute for advice from a qualified lawyer.
